# 面诊档案字段表

> 这是本 Skill 的输出骨架。字段顺序、名称、填写规则都在这里定义，改字段先改这份文件。

---

## 三级标注（最重要的一条规则）

**每个字段的值，必须能归到下面三类之一，不许出现第四种。**

| 标注 | 含义 | 什么时候用 |
|---|---|---|
| `【原话】` | 直接从转写稿摘的原文，一字不改 | 客户诉求、异议、报价、承诺 —— 这些将来要复盘，必须留原话 |
| `【转述】` | 从对话归纳出的事实，不是原句 | 既往史、评估结论、方案要点 |
| `未提及` | 整段对话里没有这个信息 | 客户没说过、也没人问过 |
| `未询问` | 该问但没人问 | **和"未提及"不是一回事**，见下方说明 |

### `未提及` 与 `未询问` 的区别（这是档案能不能用的关键）

- `未提及`：对话里出现过这个话题，但客户没说自己的情况。例：聊到过敏，客户只说了"我不过敏"，没提具体药物。
- `未询问`：整个对话**根本没人问过**这件事。例：全程没人问过有没有基础疾病。

为什么必须分开？因为**下一步动作完全不同**：

- `未提及` → 已经聊到了，客户自己没说，可以在下次沟通时追问
- `未询问` → 流程有漏洞，这是咨询流程本身缺了一环，要补的是话术和流程

如果全写成"未提及"，你就看不出自己哪一步漏了。

## 字段定义

### A. 会话信息

| 字段 | 填什么 | 规则 |
|---|---|---|
| 日期 | 转写稿的文件名日期或元数据 | 格式 `YYYY-MM-DD`，只在原文能确定时填 |
| 时长 | 通话/面诊时长 | 从元数据取，单位分钟 |
| 参与人 | 有几个人说话，各自判断的角色 | 角色从**内容**判断，不看编号，见 `提取规则.md` 第 1 条 |
| 会话类型 | 初诊 / 复诊 / 术后回访 / 线上咨询 / 售后处理 | 选一个，判不出来写 `待确认` |

### B. 客户基本信息

| 字段 | 填什么 |
|---|---|
| 称呼 | 对话里怎么称呼这个客户（`【客户】`代替真名） |
| 年龄段 | 只在客户自己说过年龄或明显提到（"我今年35"）时填，否则 `未提及`。**不许从声音或照片推测** |
| 来源渠道 | 怎么来的：老客转介绍 / 抖音 / 小红书 / 朋友带 / 门店自然客流 |
| 到店次数 | 第几次来 |
| 身份背景 | 影响决策的信息：职业、婚育、近期重要事件（结婚、面试、出差） |

### C. 主诉（客户主动提出的诉求）

最多 5 条，按客户强调程度排序。每条必须 `【原话】`。

写法：

```
1. 【原话】"我这个太阳穴凹得特别明显，显得整个人很凶"
2. 【原话】"我就想让脸小一点，别的都不动"
```

> **注意**：这里是**客户说的**，不是咨询师总结的。如果客户没明确说，写 `未提及`，不要把咨询师的建议倒推成客户的主诉。

### D. 关注点与情绪

| 子字段 | 填什么 |
|---|---|
| 反复提及的部位 | 客户提到 2 次以上的部位，说明真的在意 |
| 核心焦虑 | 客户真正怕的是什么：显老 / 显凶 / 显假 / 被看出做过 / 花钱没效果 |
| 情绪状态 | 平静 / 犹豫 / 焦虑 / 明显抗拒 / 急于解决 |
| 触发事件 | 什么事让客户现在来（同学聚会、被说显老、照镜子受不了） |

### E. 既往史

医美面诊最容易出事的地方 —— 记错既往史会直接影响方案安全。

| 子字段 | 填什么 | 特别提醒 |
|---|---|---|
| 做过的项目 | 项目名 / 时间 / 在哪做的 / 打的什么材料 / 层次 / 效果满意吗 | 一次一条，不要合并 |
| 不满意的地方 | 客户对既往项目的具体不满（"上次打完脸变宽了"） | 这是本次方案的最大约束 |
| 过敏史 | 药物、材料、麻药 | 没问过 → `未询问` |
| 基础疾病 | 高血压、糖尿病、免疫病、凝血功能 | 没问过 → `未询问` |
| 用药情况 | 抗凝药、激素、避孕药 | 没问过 → `未询问` |
| 特殊时期 | 孕期、哺乳期、经期、备孕 | 没问过 → `未询问` |
| 手术史 | 假体、截骨、其他外科手术 | 和注射史分开记 |

**项目名的坑**（ASR 同音字 + 项目相似）：

| 不能混 | 为什么 |
|---|---|
| 超声炮 / 超声刀 | 两个不同设备，能量层次不同 |
| 热玛吉 / 热拉提 / 黄金微针 | 都是射频但作用层次不同 |
| 水光针 / 微针 | 一个是注射，一个是机械刺激 |
| 玻尿酸 / 胶原蛋白 / 少女针 / 童颜针 | 材料完全不同，溶解性也不同 |
| 肉毒素 / 玻尿酸 | 最常见混淆 |

原文听不清或 ASR 明显错字时，**保留原文并加 `[?]`**，例如：`奥斯尼[?]`。不要替客户"猜"成某个项目 —— 猜错会误导方案。

### F. 面部评估

| 子字段 | 填什么 |
|---|---|
| 部位 | 额头 / 太阳穴 / 苹果肌 / 鼻唇沟 / 下颌缘 / 下巴 / 眼周 … |
| 观察到的问题 | `【转述】` 咨询师或医生说了什么（凹陷、下垂、不对称、材料堆积） |
| 依据 | 客户自述 / 现场观察 / 对比旧照片 / 触诊 |

一行一个部位。**区分"客户自己觉得"和"医生看出来"** —— 这两个经常不一致，不一致本身就是重要信息。

### G. 推荐方案

| 子字段 | 填什么 |
|---|---|
| 项目 | 具体项目名 |
| 部位 | 打哪里 |
| 剂量/单位 | 几支、几个单位、几次 |
| 层次 | 骨膜上 / 皮下 / 真皮（原文说了才填） |
| 频次/疗程 | 一次 / 三次一疗程 / 间隔多久 |
| 是否已确认 | 客户同意了 / 只是提了一下 / 客户明确拒绝 |

**方案要区分提出方**：`【医生提出】` / `【客户主动要求】` / `【咨询师建议】`。客户主动要的项目和自己被推荐的项目，成交难度完全不同。

### H. 报价与优惠

| 子字段 | 填什么 |
|---|---|
| 单项价格 | 每个项目对应金额（原价 / 折后价分开写） |
| 打包价 | 组合优惠总价 |
| 定金 | 收了多少、能不能退、能不能抵 |
| 活动 | 什么活动、截止时间 |
| 付款方式 | 全款 / 分期 / 定金锁价 |

金额一律 `【原话】`，**原文没提到的价格不许估算**，写 `未提及`。

### I. 客户异议

这是全场最有价值的部分 —— 成交卡在哪，全在这里。

一条异议一行：

```
异议 1：【原话】"会不会打完脸变得很僵啊"
        类型：效果担忧
        咨询师回应：【原话】"我们用的是小分子，打得很浅"
        是否化解：客户仍有顾虑（后面又问了一次）
```

异议类型固定这几类，方便统计：`价格` / `安全` / `效果` / `恢复期` / `信任` / `家人反对` / `决策时间`。

**必须记原话，不许改写。** 改写过就看不出客户真实的表达方式，也没法拿来做话术训练。

### J. 决策状态

| 状态 | 判断依据 |
|---|---|
| 已成交 | 明确付款、约了时间、签了单 |
| 待定 | 说"我考虑一下""回去想想"，但没有明确拒绝 |
| 暂缓 | 明确说了时间点（"等下个月发工资"） |
| 流失风险 | 明确拒绝、比价、说要再看看别家 |
| 已流失 | 明确说不做了 |

附一句 **卡点**：卡在价格、卡在信任、卡在家人、卡在恢复期。

### K. 下一步

| 字段 | 填什么 |
|---|---|
| 动作 | 具体做什么（发对比照片、算方案、约时间、寄样品） |
| 谁来做 | 咨询师 / 医生 / 客服 / 客户自己 |
| 时间 | 明确到日期或"3 天内" |
| 依据 | 客户原话里承诺或要求的事 |

原文里没有任何约定的，写 `未提及`，不要自己编一个"建议 3 天内回访"。

### L. 合规风险提示

对话里出现的、**将来用于宣传会违规**的表述。只标出来，不改写，详细检查交给 `合规文案审查`。

典型：

- 承诺效果："保证能维持一年""做完肯定好看"
- 安全性断言："这个绝对安全""一点风险都没有"
- 贬低他人："外面给你打的那些都是垃圾"
- 前后对比承诺："做完给你拍对比照发朋友圈"

发现就在档案末尾列一条，注明原话和说话人。

## 字段缺失时的处理

档案不要求填满，但**必须显式标注缺口**。输出末尾固定加一段：

```
本次档案缺口（下次沟通要补的）
- 未询问：过敏史、凝血功能
- 未提及：预算范围
- 待确认：超声炮[?] 的具体型号
```

这一段比填满的档案更有用 —— 它直接告诉你下一步该问什么。
