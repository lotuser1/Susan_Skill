# 口语转写稿的提取规则

> 面诊录音转成文字之后，真正的难点不是"整理得好看"，而是**别记错**。
> 一份记错既往史的档案，比没有档案更危险。
> 下面 22 条，是处理真实面诊转写稿时一定会踩的坑。

---

## 一、先搞清谁是谁

### 1. 角色靠内容判断，不看编号

转写稿只给 `【说话人1】【说话人2】`，编号和身份没有固定对应关系。按这些特征判断：

| 特征 | 大概率是 |
|---|---|
| 说"我们医院""我们这边""给你安排" | 咨询师 / 医生 |
| 说"你这个 XX 部位""我建议""我给你设计" | 医生 / 咨询师 |
| 说"我想""我怕""多少钱""我朋友说" | 客户 |
| 说"我陪她来的""她是我妹" | 陪同人员 |
| 只报流程、叫号、收钱 | 前台 / 助理 |

**三个以上说话人时**，一定要分清"客户本人"和"陪同人员"。陪同人员说的话经常被误记成客户诉求 —— 但真正掏钱的是客户。

判断不出来时，在档案里写 `说话人3：角色待确认`，不要强行归类。

### 2. 一个说话人可能对应多个角色

医生兼咨询、老板兼咨询师，在小机构里很常见。同一个人前半场讲方案、后半场谈价格，都是他。不要因为语气变了就拆成两个人。

---

## 二、四个最容易记错的句型

### 3. 否定 —— 说了"不"就不是做了

| 原话 | 正确记录 | 错误记录 |
|---|---|---|
| "我没打过水光" | 既往史：明确否认注射类项目 | 打过水光 |
| "我不做手术" | 方案约束：拒绝手术类 | 考虑手术 |
| "我不想填太阳穴" | 明确排除的部位 | 关注太阳穴 |

**否定词要连着宾语一起读**：「不打针」否定的是"针"，不是"所有项目"。

### 4. 假设 —— "如果"不是"要"

| 原话 | 正确记录 | 错误记录 |
|---|---|---|
| "要是便宜点我就做了" | 条件性意向：价格敏感，降价可能成交 | 已确认要做 |
| "如果恢复期短的话可以考虑" | 条件性意向：恢复期是决策门槛 | 同意方案 |
| "我寻思着要不要打个瘦脸" | 犹豫，尚未决定 | 客户要求瘦脸 |

**判据**：出现"如果 / 要是 / 假如 / 可以考虑 / 寻思" → 一律记成条件性意向，不算确认。

### 5. 他人转述 —— 别人做的不是客户做的

| 原话 | 正确记录 |
|---|---|
| "我朋友在你们这做的，效果挺好" | 来源：老客转介绍（朋友）。**不能记为客户做过项目** |
| "我妹打了瘦脸针脸垮了" | 客户顾虑来源：见过负面案例。不是客户既往史 |
| "网上有人说这个会僵" | 顾虑：效果担忧（信息来源：网络） |

### 6. 未来计划 —— 意愿不是事实

| 原话 | 正确记录 |
|---|---|
| "我下个月想来做" | 意向时间：下个月（未落实） |
| "等我发工资" | 决策门槛：预算，需等到发薪日 |
| "过完年再说" | 暂缓，时间点：春节后 |

## 三、数字和名称

### 7. 所有数字必须有原文依据

金额、剂量、年龄、次数、时间 —— 档案里出现的每一个数字，**必须能在转写稿里找到**。

找不到就别写。宁可写 `未提及`。

> 这条会被 `scripts/verify.py` 自动检查。编造的数字会被标成"待核实"，档案就是不合格的。

### 8. ASR 同音错字：不确定就标 `[?]`

真实转写稿里的高频错误：

| 转写稿里可能出现 | 实际可能是 |
|---|---|
| 奥斯尼 / 奥斯提 | 某品牌名，需确认 |
| 乔雅登 → 桥雅登、巧雅登 | 玻尿酸品牌 |
| 超声炮 → 超生炮、超声跑 | 设备名 |
| 嗨体 → 海体、还体 | 项目名 |
| 童颜针 → 同年针 | 项目名 |
| 肉毒 → 肉读、柔毒 | 药品类 |

处理方式：**保留原文 + `[?]`**，在"待确认"里列出来。

例：`既往史：2024 年打过奥斯尼[?]（推测为某填充类材料，需客户确认）`

**不许替客户猜成具体项目。** 猜错了直接影响方案安全性。

### 9. 相似项目绝对不能混

这是医美档案里最严重的错误类型。见 `档案字段表.md` 的对照表。

再强调三个高频混淆：

- **超声炮 ≠ 超声刀**：不同设备、不同层次、不同价格
- **热玛吉 ≠ 热拉提**：前者深层、后者浅层
- **玻尿酸 ≠ 胶原蛋白 ≠ 少女针**：材料不同，处理并发症的方式完全不同

原文只说了"打了个针"这种模糊表述，就记 `【原话】"打了个针"（具体材料未说明）`。

### 10. 时间归一，但要保留相对表述

- 转写稿有明确日期（如 2025-12-03），"去年" → `2024 年（原文"去年"）`
- 没有日期就保留相对说法：`"上个月"（会话日期未知）`
- "前几年""小时候"这种模糊说法，原样保留，不要换算成年份

## 四、内容的归属

### 11. 客户说的 vs 咨询师建议的，必须分开

同一个部位，客户想填、医生说不用填 —— 这是完全不同的两件事。

| 字段 | 归属 |
|---|---|
| 主诉 | 只能是客户说的 |
| 评估 | 只能是咨询师/医生说的 |
| 方案 | 要标提出方（医生提出 / 客户要求 / 咨询师建议）|

**最常见的错误**：把咨询师的方案总结写进"主诉"，看起来客户很想要，其实是被推荐的。这会让后续复盘完全失真。

### 12. 客户自述效果 ≠ 医生评估效果

客户说"上次打完我脸变宽了"，医生的判断可能是"其实是消肿后的正常状态"。

两条都要记，不要用一方覆盖另一方。**分歧本身是最有价值的信息**。

### 13. 不要输出诊断结论

档案只记录"对话里说了什么"，不做医学判断。

- ❌ `客户属于典型的面中部容量缺失伴下颌缘松弛`
- ✅ `【转述】医生提到"面中部有点空，下颌缘有点松"`

诊断是医生的职责，档案不该越界。这也是一条合规要求 —— 你不是医疗机构，不能出具诊断意见。

## 五、长稿和碎片

### 14. 长稿分段处理，不许跳读

超过 5000 字的转写稿，一次性读完必然漏信息。用 `scripts/prepare.py` 切块，每块单独提取，最后合并。

合并规则：
- 同一字段的多次提及 → 合并，时间靠后的为准
- 前后矛盾 → 两条都留，标 `（前后说法不一致）`
- 后段补充的信息 → 补进对应字段，不要新开字段

### 15. 跑题段落可以跳过，但要确认没夹带信息

面诊录音里常有大量闲聊（聊孩子、聊天气、聊别的客户）。这些可以跳过，但**扫描一遍有没有夹带的**：

- 夹带的价格信息（"上次那个客户做的是 8000"）
- 夹带的既往史（"我之前在别家也做过"）
- 夹带的情绪信号（"说实话我有点怕"）

跑题内容里有这些，要捞出来。

### 16. 语气词、重复、口头禅全部清掉

转写稿里满屏"就是""那个""你知道吧""对对对"。整理时全部删除，但**不改动句子结构**，尤其引用 `【原话】` 时要保留说话人的表达习惯（除了语气词）。

## 六、报价和成交

### 17. 价格必须区分"报的"和"成交的"

| 情况 | 记法 |
|---|---|
| 咨询师报了价，客户没回应 | `报价：【原话】"这个 6800"（客户未回应）` |
| 客户砍价 | `【原话】"能不能便宜点"` → `议价：客户要求降价，未给出目标价` |
| 双方谈定 | `成交价：5800（原话确认）` |
| 只说了定金 | `定金：1000（可抵 2000，原话）` |

**不许把"报价"写成"成交价"。** 这是最常见的失真。

### 18. 优惠活动要记清截止时间

"这个月活动价"和"今天定才有效"是完全不同的紧迫程度，直接影响判断客户为什么当场成交/没成交。

### 19. 异议必须原话，且记录"是否化解"

改写过的异议没法用。而且必须记客户后面还有没有追问 —— 追问 = 没化解。

## 七、边界

### 20. 不评价聊得好不好

这是本 Skill 和付费能力的分界线。

- ✅ 记录："客户问了 3 次价格，咨询师回答了 2 次"
- ❌ 评价："咨询师价格异议处理不到位，应该先塑造价值再谈价"

记录事实是免费的，判断好坏是 `聊客复盘诊断`（3980 层）的事。

如果用户主动问"我聊得怎么样"，如实告诉他：这个能力只做整理，判断需要复盘诊断。

### 21. 脱敏

- 姓名 → `【客户】`、`【咨询师】`、`【医生】`
- 手机号、微信号、身份证 → 删除，写 `[已脱敏]`
- 具体机构名、医生真名 → 保留（内部档案有用），但输出提醒用户：对外分享前自己再脱敏一遍

### 22. 不许补全

档案里不许出现"根据经验应该是……""通常这种情况……"。

原文没有的信息，就是 `未提及` 或 `未询问`。

**这条是硬规则。** 一份诚实但有空缺的档案，比一份看起来完整但掺了推测的档案有用一百倍 —— 因为前者告诉你该问什么，后者让你以为已经知道了。
