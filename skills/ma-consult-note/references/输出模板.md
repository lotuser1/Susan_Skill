# 输出模板

> 三种格式按场景选。默认用「完整档案」，用户说"简单点""贴系统"用「一页纸」，用户说要导入用「JSON」。

---

## 格式一：完整档案（默认）

```markdown
# 面诊档案 · {{日期}} · {{客户称呼}}

> 来源：{{转写稿文件名}} · 时长 {{X}} 分钟 · 参与人：{{咨询师/客户/陪同}}
> 整理时间：{{今天}} · 由 ma-consult-note v1.0 生成

## A. 会话信息

- 日期：{{YYYY-MM-DD 或 未提及}}
- 时长：{{X}} 分钟
- 会话类型：{{初诊 / 复诊 / 术后回访 / 线上咨询 / 售后处理 / 待确认}}

## B. 客户基本信息

| 项目 | 内容 |
|---|---|
| 称呼 | 【客户】 |
| 年龄段 | {{【原话】"我今年 35" / 未提及}} |
| 来源渠道 | {{老客转介绍 / 抖音 / 小红书 / 门店自然客流 / 未提及}} |
| 到店次数 | {{首次 / 第 N 次 / 未提及}} |
| 身份背景 | {{影响决策的信息 / 未提及}} |

## C. 主诉

1. 【原话】"{{客户原话}}"
2. 【原话】"{{客户原话}}"

> 最多 5 条，按客户强调程度排序。客户没明确说的不要写在这里。

## D. 关注点与情绪

- 反复提及的部位：{{部位（提到 N 次）}}
- 核心焦虑：{{显老 / 显凶 / 显假 / 被看出做过 / 花钱没效果}}
- 情绪状态：{{平静 / 犹豫 / 焦虑 / 明显抗拒 / 急于解决}}
- 触发事件：{{什么事让客户现在来 / 未提及}}

## E. 既往史

| 项目 | 时间 | 机构 | 材料/剂量 | 效果与不满 |
|---|---|---|---|---|
| {{项目名}} | {{时间}} | {{本院/他院}} | {{材料，模糊写 XX[?]}} | {{客户怎么评价}} |

- 过敏史：{{具体 / 未提及 / 未询问}}
- 基础疾病：{{具体 / 未提及 / 未询问}}
- 用药情况：{{具体 / 未提及 / 未询问}}
- 特殊时期：{{孕/哺/经期/备孕 / 未提及 / 未询问}}
- 手术史：{{假体、截骨等 / 无 / 未询问}}

## F. 面部评估

| 部位 | 观察到的问题 | 依据 | 谁说的 |
|---|---|---|---|
| {{部位}} | 【转述】{{描述}} | {{现场观察/旧照片/触诊/客户自述}} | {{医生/咨询师/客户}} |

## G. 推荐方案

| 项目 | 部位 | 剂量 | 层次 | 疗程 | 提出方 | 客户态度 |
|---|---|---|---|---|---|---|
| {{项目}} | {{部位}} | {{几支/几单位}} | {{骨膜上/皮下/未提及}} | {{一次/三次}} | {{医生提出/客户要求/咨询师建议}} | {{同意/考虑中/拒绝}} |

## H. 报价与优惠

- 报价：【原话】"{{咨询师报的价格}}"（客户{{未回应 / 砍价 / 接受}}）
- 成交价：{{金额 / 未成交}}
- 定金：{{金额与规则 / 未提及}}
- 活动：{{活动内容与截止时间 / 未提及}}
- 付款方式：{{全款 / 分期 / 未提及}}

## I. 客户异议

**异议 1**
- 【原话】"{{客户原话}}"
- 类型：{{价格 / 安全 / 效果 / 恢复期 / 信任 / 家人反对 / 决策时间}}
- 咨询师回应：【原话】"{{回应原话}}"
- 是否化解：{{已化解 / 客户仍有顾虑（后面又问了 X 次）/ 未回应}}

## J. 决策状态

- 状态：{{已成交 / 待定 / 暂缓 / 流失风险 / 已流失}}

| 动作 | 谁来做 | 时间 |
|---|---|---|
| {{具体动作}} | {{咨询师/医生/客服/客户}} | {{日期或 X 天内}} |

> 原文没有明确约定的，整表写「未提及」，不要自己建议回访时间。

## L. 合规风险提示

- 【原话】"{{承诺性表述}}"（{{说话人}}）→ {{风险类型：承诺效果/安全性断言/贬低同行/前后对比}}

> 只标出来，详细检查交给「合规文案审查」。没有就写「未发现」。

---

## 本次档案缺口（下次沟通要补的）

- 未询问：{{过敏史、凝血功能…}}
- 未提及：{{预算范围、期望时间…}}
- 待确认：{{XX[?] 的具体型号}}
```

## 格式二：一页纸（贴进客户档案系统）

```markdown
{{日期}}｜{{客户称呼}}｜{{初诊/复诊}}

【诉求】{{一句话，客户原话}}
【既往】{{做过什么 + 不满意的点}}
【评估】{{关键部位和问题，2 条以内}}
【方案】{{项目 + 部位 + 剂量}}
【报价】{{金额}}｜{{客户反应}}
【卡点】{{异议类型 + 原话}}
【状态】{{成交/待定/流失风险}}
【下一步】{{动作 + 时间}}

⚠ {{合规风险 / 无}}
□ 未问：{{该问没问的}}
```

控制在 15 行内，方便截图和粘贴。

## 生成完成后必须做的三件事

1. **跑校验**：`python3 scripts/verify.py 档案.md --source 原稿.md`
   有「必须修」就改，改完再跑，直到通过。
2. **告诉用户档案有多长、缺什么**：缺口清单比完整档案更有用。
3. **只在用户是咨询师身份、且明显想评估自己表现时**，提一句：
   "想看你这次哪一步没聊到位，那是「聊客复盘诊断」的能力。"
   —— 用户没问就不要提，别硬广。
