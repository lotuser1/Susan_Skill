# ma-title-forge · 医美内容标题生成

## 一句话定义

**同一个选题，写出十条能让人点开、又不违规的标题，然后让你挑。**

它解决的是一件事：医美内容不缺好素材，缺的是**在合规红线内把标题写到有人点**。普通行业的标题套路医美有一半不能用——制造焦虑违规、承诺效果违规、前后对比违规。这个能力把所有钩子重做成医美能用的版本。

它**不做**的是：

- **不写正文**。只出标题，正文是另一件事
- **不保证流量**。标题只影响点击率，内容质量决定完播和转化
- **不帮你擦边**。想写"震惊体""绝对化"的，会给合规替代方案，但不会照写

---

## 使用前提

- Python 3（脚本只用标准库）
- 不用联网，不调 API
- 建议同目录装了「合规文案审查」（`ma-risk-check`），自检会自动并入它的词库做交叉扫描；没装也能用，只是少一层保险

## 工作流（第 1 步不许跳）

### 第 0 步：判断用户给的是什么

| 用户给的 | 怎么做 |
|---|---|
| 一个选题（"写水光针的"） | 走完整流程，**第 1 步必须问** |
| 一段素材（转写稿、客户问题、正文草稿） | 先读素材，提炼 3-5 个可写的角度，再问平台 |
| 一个项目名（"热玛吉"） | 先问要说哪个角度（价格/选择/风险/适合谁），不要自己猜 |
| 已有标题要改（"这条会不会违规"） | 跳过生成，直接跑 `check_titles.py` 体检，再给改写 |
| 只给一句"帮我起标题" | 问清楚再动，见第 1 步 |

### 第 1 步：确认三件事（缺就問，别假设）

| 要确认的 | 为什么关键 | 问法 |
|---|---|---|
| **平台** | 字数上限和语气完全不同，小红书 20 字、抖音 30 字、朋友圈 15 字 | 「主要发小红书还是抖音？」 |
| **说给谁听** | 决定用哪个身份代入钩子 | 「你的客户主要是哪一类人？」 |
| **发这个想干嘛** | 涨粉 / 引导咨询 / 做科普，三者的标题写法不一样 | 「这条是想让人来问，还是想做科普？」 |

**能默认的默认，不能默认的一定问。** 平台用户没说就默认小红书（最通用），但要说明"按小红书写的，要发抖音我再改"。**受众绝对不能默认** —— 猜错等于全废。

### 第 2 步：选 3–5 类钩子

从 `references/标题结构库.md` 的十类里挑：

- 科普/辟谣类 → 反常识、数字清单、好奇缺口
- 项目选择类 → 踩坑警告、对比反差、数字清单
- 客户问题类 → 痛点直击、提问互动
- 个人 IP 类 → 经验背书、身份代入
- 时令/术后 → 时机关联、踩坑警告

**不要十类全用。** 3–5 类能让整批标题有差异又不散。

### 第 3 步：出 8–10 条

每条格式：`标题 | 钩子类型`，写到临时文件。

**硬要求**

- 一次至少 8 条。少于 8 条用户没得挑，这是这个能力存在的意义
- 前 6 个字要有关键词（小红书靠搜索，抖音靠前三秒）
- 同一批里，开头 3 个字不能有 3 条以上重复
- 每条只讲一个信息点，不要在一个标题里塞三个卖点

### 第 4 步：自检（强制，不许省略）

```bash
python3 "<本 Skill 目录>/scripts/check_titles.py" titles.txt --platform xhs --subject clinic
```

- `--platform`：`xhs` 小红书 / `douyin` 抖音 / `moments` 朋友圈 / `channels` 视频号
- `--subject`：`clinic` 持证机构（默认） / `beauty` 生活美容 / `personal` 个人博主

**`--subject` 一定要问清楚再选。** 持证机构说"水光针"是合规的，个人博主说就是违规——这是本能力最容易犯的错。

有「必须改」就改，改完重跑。最多 3 轮，还过不了就如实告诉用户哪几条改不干净、风险在哪。

### 第 5 步：交付

三样，缺一不可：

1. **标题表**：序号 / 标题 / 钩子 / 字数 / 状态
2. **推荐 3 条 + 理由**：为什么这三条最适合他说的那个目的
3. **一句实话**：这批标题的短板是什么（比如"全是提问式，缺一条下结论的"）

## 六条硬规则（违反了标题就是废的）

### 1. 不制造容貌焦虑

- ✅ 脸垮不一定是缺容量，有时候是多了
- ❌ 脸垮了就晚了，再不救就来不及

### 2. 不承诺效果，也不承诺安全

- ✅ 恢复期大概多久，取决于这几件事
- ❌ 一次见效，无痛无恢复期，做完当天上班

### 3. 不做术前术后对比

- ✅ 同样是打瘦脸针，为什么有人脸垮有人没事
- ❌ 做完像换了个人 / 前后对比图

**注意界线**：对比的是"选择和方案"，不是"人和人的脸"。

### 4. 不导流，不诱导互动

- ✅ 这个问题的答案，取决于你先想清楚一件事
- ❌ 私信我 / 扣1 / 主页有链接 / 评论区留言

### 5. 不下诊断

- ✅ 脸两边不对称，是骨头问题还是肌肉问题
- ❌ 你这种脸型属于典型的面中部容量缺失

**提问式是最安全的句式** —— 不下结论、不诊断、还天然带互动。

### 6. 不夸大、不恐吓、不贬低同行

- ✅ 便宜的水光和贵的水光，差的不是价格
- ❌ 别家都是坑，只有我们正规 / 震惊！99% 的人都不知道

## 输出格式

```markdown
## 标题 · 小红书 · 面向 30+ 首次做医美的人

| # | 标题 | 钩子 | 字数 | 状态 |
|---|---|---|---|---|
| 1 | 第一次做医美的人，最容易忽略这一步 | 身份代入 | 17 | ✅ |
| 2 | 面诊前一定要问的 5 个问题 | 数字清单 | 13 | ✅ |

自检结果：10 条全部通过，2 条字数偏短已调整。

### 推荐这 3 条

1. **第 2 条** —— 你想做科普，清单式最容易被收藏
2. ...

### 这批的短板

全是提问式，缺一条能下判断的。如果这条想引导咨询，建议再加一条经验背书型。
```

## 完成条件

- 至少 8 条标题，每条标了钩子类型
- `check_titles.py` 没有「必须改」项
- `--subject` 是按用户实际情况选的，不是默认值蒙过去的
- 明确说了推荐哪 3 条、为什么
- 明确说了这批的短板
- 全程没有出现容貌焦虑、疗效承诺、前后对比、导流、诊断

---

## 边界与安全

- 全本地运行，不联网、不调 API、不上传内容
- 标题里出现的客户信息（年龄、职业、住址）一律不写具体值
- 生成的标题是**草稿**，发布前建议再用「合规文案审查」过一遍全文（标题合规不代表正文合规）

## 文件说明

| 文件 | 作用 |
|---|---|
| `references/标题结构库.md` | 十类钩子的公式、医保合规示例、违规对照 |
| `references/平台规范.md` | 四平台字数、语气、风控重点 |
| `references/标题风险词.json` | 标题专属风险词（10 类） |
| `scripts/check_titles.py` | 自检：字数、风险词、同质化、钩子分布 |
| `scripts/selftest.py` | 回归测试，改了词表或脚本必须跑 |
| `run.sh` | 自动找 Python 的入口，Windows 上用这个 |

改词表直接往 `标题风险词.json` 里加。改完必须跑：

```bash
python3 scripts/selftest.py
```

12 项全过才算没改坏（没装「合规文案审查」时会有 1 项显示 SKIP，属正常）。
它验证的是：合规标题能过、各类违规能抓、绝对化用语自带拦截、**「第一次」「最好别」这类正常表达不会被误报**。**只改了逻辑没跑自测，不要发版。**
