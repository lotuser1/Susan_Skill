# ma-risk-check · 医美文案合规检查

## 一句话定义

**回答「这段文案能不能发」，并告诉你具体改哪个词、改成什么。**

它解决的是：
- 写完文案不敢发，怕被平台限流、下架、封号
- 怕违反广告法被市场监管处罚（医美广告罚则 20 万起）
- 通用违禁词工具查不出医美特有的坑（安全性断言、前后对比、容貌焦虑）

它**不做**的是：
- **不保证通过审核**。这是基于公开规则的预检，不是平台预审，也不替代法务判断
- **不检查图片和视频本身**。文字层由脚本完成，图像层（前后对比画面、二维码、联系方式）需要你自己看 —— 见下方「多模态检查」
- **不帮你写文案**。只告诉你哪里有问题、建议怎么改

---

## 使用前提

- 需要 Python 3（脚本只用标准库，无需 pip 安装任何包）
- 无需任何 API Key，完全本地运行，文案不会上传到任何地方

---

## 用法

```bash
# 直接检查一段文案
python3 scripts/check.py --text "这段文案能不能发"

# 检查文件
python3 scripts/check.py --file post.txt

# 管道
cat post.txt | python3 scripts/check.py

# 指定平台和主体
python3 scripts/check.py --text "..." --subject clinic --platform xhs

# AI/数字人生成的内容
python3 scripts/check.py --text "..." --ai-generated

# 输出格式：text（默认，人读）/ md（贴到文档）/ json（程序用）
python3 scripts/check.py --text "..." --format md

# 自检（验证脚本与词库是否正常）
python3 scripts/check.py --selftest
```

也可以用 `bash run.sh --text "..."`（自动找 Python）。

## 两个关键参数

### `--subject` 发布主体是谁（**决定规则对不对，必填意识**）

| 取值 | 含义 | 典型红线 |
|---|---|---|
| `clinic` | 持证医疗美容机构（默认） | 禁安全性断言、前后对比、功效承诺 |
| `beauty` | 生活美容馆 / 美容院 | **额外禁用全部诊疗术语**（水光针、超声炮、填充、激光脱毛…），用了就是违法发布医疗广告 |
| `skincare` | 普通美妆护肤 | 禁用医疗功效暗示（美白、抗炎、医用级…） |

> **这是本 Skill 与通用违禁词工具最大的区别。**
> 同一个词「水光针」：持证机构说，合规；楼下美容馆说，违法。
> 通用工具不做这个区分，所以它要么误报一大堆，要么漏掉真正的坑。

### `--platform` 发到哪个平台

`douyin`（抖音）/ `xhs`（小红书）/ `sph`（视频号）/ `all`（默认，最严）

差异要点：
- **抖音**：直播实时抓取口播、字幕、背景贴纸，说错当场断播，3 次违规连带账号限流
- **小红书**：评论区、置顶文案同样在审核范围；私信导流直接封号
- **视频号**：社交传播会加重处罚；权威冒用（央视推荐/官方认证）严查；医疗健康内容需资质认证，且主要出镜人须为认证人

## 检查流程（脚本已内置，了解即可）

1. **跑词库**：20 类 / 408 词，按主体和平台过滤后逐词匹配
2. **跑语义规则**：R1–R13，判断「词没问题但组合起来违规」
3. **出报告**：分「必须改」/「建议改」两档

### 语义规则能抓到什么（纯关键词工具抓不到）

| 文案 | 关键词工具 | 本 Skill |
|---|---|---|
| 「这个项目很安全」 | 通过 | **违规**——医美广告禁止安全性断言 |
| 「保证你做完比现在好看」 | 通过 | **违规**——承诺效果 |
| 「7天淡斑，一个月逆袭」 | 通过 | **违规**——速效承诺 |
| 「这个缺陷一定要改善，不然显老又显穷」 | 通过 | **违规**——制造容貌焦虑（2023 年以来监管整治重点）|
| 「科普一下水光针，想做的私信我」 | 通过 | **违规**——以科普形式变相发布医疗广告 |

## 多模态检查（脚本做不到的部分，你要自己看）

如果文案配了图片或视频，**额外检查这几项**，纯文字工具永远查不出来：

- [ ] **术前术后对比画面**：同一人脸的前后对照，医美广告明令禁止，即使文案一个违禁词都没有也会被判违规
- [ ] **二维码 / 微信号 / 手机号**：出现在画面里同样算导流
- [ ] **患者形象或聊天截图**：以患者名义作证明违规
- [ ] **AI 生成内容**：数字人/AI 生成的视频图文**必须加显式 + 隐式标识**（《人工智能生成合成内容标识办法》2025-09-01 施行），未标识会限流、下架、封号

配图时加上 `--ai-generated`，脚本会一并检查标识要求。

## 输出说明

| 等级 | 含义 | 怎么处理 |
|---|---|---|
| **必须改** | 法律红线或平台硬规 | 发布前必须改 |
| **建议改** | 不影响合法，但影响推流/易被误判 | 建议改 |
| **可用但需注意** | 当前主体可以用，但不得搭配功效承诺 | 留意即可 |

每条会给出：命中词 / 类别 / 法规依据 / 上下文 / **具体改成什么**。

---

## 完成条件

- 报告里「必须改」为 0 条
- 如含图片/视频，多模态检查清单已逐项确认
- 已明确告知用户：这是预检，最终以平台审核和监管执法为准

---

## 边界与安全

- **只读**：不修改用户任何文件，只输出报告
- **全本地**：不联网、不调用 API、文案不外传
- **每次输出都要带免责声明**：基于公开规则整理，非平台预审结论

## 词库维护

词库在 `references/违禁词库.json`（20 类 408 词），语义规则在 `references/上下文语义规则.md`。

新增词：在对应类别的 `words` 数组里加，可在同类 `replacements` 里给出替代表达。
新增语义规则：编辑 `scripts/check.py` 的 `SEMANTIC_RULES`。
改完后跑 `python3 scripts/check.py --selftest` 确认没有引入误报。
