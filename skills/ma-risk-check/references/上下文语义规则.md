# 上下文语义违规规则

> 关键词表只能查出"这个词不能说"。但平台审核和监管执法真正抓的，往往是**词本身没问题、组合起来违规**的情况。
> 本文件定义这类规则。检查时必须**先跑词库，再跑语义规则**，两者结合才算完整。

---

## 一、为什么必须有这一层

举三个真实场景：

| 文案 | 关键词检查 | 实际判定 |
|---|---|---|
| 「这个项目很安全」 | 通过 | **违规**——医美广告禁止对安全性作断言 |
| 「我们做过的客人里，大多数反馈维持时间挺长」 | 通过 | 合规——主观体验表述，平台最认可的句式 |
| 「3天见效，无效退款」 | 命中「3天见效」「无效退款」 | 违规（关键词层就能抓） |
| 「做了之后老公都说好看」 | 通过 | **违规**——制造容貌焦虑，把容貌与他人评价绑定 |
| 「安全」「无副作用」分开出现在两段 | 分别通过 | **违规**——同现即触发，需跨句判断 |

结论：**关键词能抓的约占 60%，剩下 40% 必须靠语义。**

---

## 二、语义规则清单

### R1 · 安全性断言（跨词组合同现）

```
触发：(安全|无风险|零风险|无副作用|完全无痛|无创伤|零恢复期|绝对安全)
      └ 单独出现"安全"不触发，需搭配断言性修饰
判定：违规（医美广告明确禁止表示安全性的断言或保证）
依据：《医疗美容广告发布合规指引》四(四)
```

正例/反例：
- ❌「这个方法很安全，没有副作用」
- ✅「术前会做充分评估，可能出现暂时性红肿，一般数天内缓解」

---

### R2 · 承诺性动词 + 效果名词

```
触发：(保证|承诺|包|一定|肯定|必定|绝对|确保|保证你)
      × (效果|见效|改善|恢复|变美|成功|满意|好看|年轻)
判定：违规
```

- ❌「保证你做完比现在好看」
- ✅「按多数人的恢复节奏，一般会有比较明显的改善」

---

### R3 · 否定式安全承诺

```
触发：(无|零|没有|不存在|不会) × (副作用|风险|痛苦|后遗症|失败|反弹|复发)
判定：违规
```

- ❌「零副作用，不会反弹」
- ✅「恢复期因人而异，大多数人反馈一周左右」

---

### R4 · 数字 + 比例 + 效果

```
触发：(\d+%|\d+成|百分之\d+|XX例) × (有效|成功|满意|改善|复购|好评)
判定：违规（宣传治愈率/有效率）
```

- ❌「有效率 95%，满意度 98%」
- ✅「在我们过去的服务案例里，大多数人的反馈是……」

---

### R5 · 时间 + 见效（速效承诺）

```
触发：(\d+天|\d+周|\d+个月|一周|一个月|立刻|马上|当场|当天|瞬间|一秒)
      × (见效|变白|变美|瘦|淡|消失|改善|紧致|逆袭)
判定：违规
```

- ❌「7天淡斑，一个月逆袭」
- ✅「按多数人的节奏，一般在数周左右逐渐看到变化」

---

### R6 · 极端副词 + 任意动词

```
触发：(根治|彻底|永远|永不|完全|全部|一律|绝对) × {动词}
判定：违规
```

- ❌「彻底解决法令纹」「永不反弹」
- ✅「针对法令纹常见的处理方式有……」

---

### R7 · 容貌焦虑（医美特有，执法重点）

```
触发：(丑|缺陷|硬伤|拉垮|显老|显穷|没气质|不上镜|被人嫌弃|嫁不出去|找不到对象)
      × (一定要改|必须|不改就|否则|完了|没救|没法看)
判定：违规（制造容貌焦虑）

追加触发：容貌 × (能力|收入|贫富|成败|素养|人缘|婚姻|职场)
判定：违规（不当关联）
```

- ❌「这个缺陷一定要改善，不然显老又显穷」
- ❌「做了这个，职场竞争力都不一样了」
- ✅「这个部位可以按你的基础做一些调整」

> 这条是医美行业**最容易被忽略**的违规类型。关键词命中率极低，但恰恰是 2023 年以来市场监管部门整治医美广告的重点方向。

---

### R8 · 前后对比（图文/视频多模态）

```
触发：文案 (术前术后|前后对比|对比图|效果图|即刻效果|蜕变|逆袭)
      或 图像/视频中检测到同一人脸的前后对照画面
判定：违规
```

> **纯关键词工具永远查不出第二条。** 图像层面的前后对比必须靠多模态识别。这是本 Skill 相对通用违禁词检测工具的核心优势。

---

### R9 · 软文变相广告（科普外壳 + 引流内核）

```
触发：(科普|科普一下|讲个知识点|专访|探店|分享一个知识)
      × (地址|电话|二维码|点击链接|主页|门店|预约|私信|到店)
判定：违规（以科普形式变相发布医疗广告）
```

- ❌「科普一下水光针，想做的私信我地址」
- ✅「科普一下水光针的原理」（不带任何引流信息）

---

### R10 · 患者名义作证明

```
触发：(顾客|客户|客人|小姐姐|粉丝) × (说|反馈|评价|见证|案例|亲测|做完说)
      且 出现具体人物形象/姓名/聊天截图
判定：违规（以患者名义、形象作推荐证明）
```

- ❌「客人做完说：老公都认不出来了」+ 术前术后图
- ✅「从方案设计逻辑上讲，这个部位一般考虑……」

---

### R11 · 未成年人指向

```
触发：(学生|高考|暑假|未成年|00后|05后) × (变美|做项目|优惠|专属|分期|贷款|首付)
判定：违规（向未成年人发送医美广告）
```

- ❌「学生党专属，暑假变美计划」

---

### R12 · 医美贷/分期诱导

```
触发：(分期|零首付|免息|贷款|借钱|花呗|信用卡) × (变美|项目|手术|做|下单)
判定：高风险（监管重点整治方向）
```

---

### R13 · AI 生成内容标识（必须标注，非禁用）

```
触发：内容由数字人/AI 生成 或 用户声明为 AI 生成
判定：必须添加显式标识，未标注将限流/下架
依据：《人工智能生成合成内容标识办法》（2025-09-01 施行）
```

- 显式标识：视频起始画面 + 播放周边显著位置加提示
- 隐式标识：文件元数据中写入生成属性、服务提供者、内容编号
- **不得恶意删除、篡改、隐匿标识**

## 三、安全句式（改造模板）

平台审核机制里最认可的，是「**用户主观表达**」句式。把确定性的医学/承诺表达，改成基于服务案例的主观反馈：

| 违规写法 | 安全写法 |
|---|---|
| 治疗 / 根治 | 针对 XX 情况的常见处理方式 |
| 100% 有效 | 在我们做过的案例里，大多数人反馈…… |
| 保证见效 | 按多数人的恢复节奏，一般…… |
| 一周见效 | 恢复节奏因人而异，一般数周左右 |
| 无副作用 | 可能出现暂时性红肿，一般数天内缓解 |
| 全网最低价 | 价格很划算 |
| 比 XX 品牌好 | 和我之前用过的另一款相比 |
| 这个缺陷必须改 | 这个部位可以按你的基础做些调整 |

## 四、平台差异速查

| 平台 | 最严的地方 | 本平台特有的坑 |
|---|---|---|
| **抖音** | 直播实时抓取：口播、字幕、直播间背景、贴纸文案全查，说错当场断播，3 次违规连带账号限流 | 「上热门」「必火」「涨粉神器」等流量词敏感；资质类词严查 |
| **小红书** | 评论区、置顶文案同样在审核范围内；私信导流直接封号 | 诱导互动（一键三连等）与私域导流是重灾区；2026-07 起对比贬低零容忍 |
| **视频号** | 社交传播：转发扩散违规内容会加重处罚 | 权威冒用（央视推荐/官方认证）、虚假福利（免费送/零元领）严查；医疗健康内容需资质认证且主要出镜人须为认证人 |

## 五、2026 新增管控（需持续跟踪）

1. **黑名单机制**：同一主体 3 次违规，旗下所有账号、店铺连带受限。
2. **网络流行词升级**：带货文案中「天花板」「绝了」「封神」「神级」直接判定极限宣传。
3. **对比类语义识别加强**：只要提到具体友商品牌名基本驳回。
4. **AI 标识强制化**：各平台已更新用户协议，未主动标识 AI 内容会限流、下架、封号。

## 六、使用方式

检查一段文案时按此顺序：

1. **定主体**：持证医美机构 / 生活美容馆 / 普通美妆？决定 `medical_term_licensed` 与 `medical_term_unlicensed` 哪一套生效。
2. **跑词库**：逐类匹配，输出命中词 + 风险等级 + 合规替代表达。
3. **跑语义规则**：R1–R13，逐条判断是否触发。
4. **多模态检查**：如含图片/视频，检查是否有前后对比画面、二维码、联系方式。
5. **出报告**：分「必须改」（法律红线）/「建议改」（影响推流）两档，每条给最小修改动作。

> 免责：本规则基于公开法规与平台规则整理，非平台预审结论。具体判定以平台审核和监管执法为准。
