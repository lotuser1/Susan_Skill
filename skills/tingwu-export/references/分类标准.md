# 医美知识库 · 板块分类标准

> 用途：给 LLM 判定每篇转写稿归属哪个板块。判定依据是**内容主旨**，不是文件名。
> 收录原则：一篇稿子横跨多个板块时，**归到它主要解决的那个环节**。
> 判不出来 → `08 无法鉴别`（终态，等人审），**不要**退回 `00 待分类`。

## 目录用途区分（容易混淆，先看这里）

| 目录 | 性质 | 说明 |
|---|---|---|
| `00 待分类` | **临时中转** | 刚下载、还没判定的稿子。归类跑完应当清空 |
| `01`～`07` | **正式板块** | 判定成功的终态 |
| `08 无法鉴别` | **终态（兜底）** | 判定过了但确实判不出来：内容太碎/太短、纯闲聊无信息量、录到噪音、素材质量存疑。放这里等人审，不要反复回退到 00 |

## 板块定义与边界

| 目录 | 收录什么 | **不**收录什么（应归到别的板块） |
|---|---|---|
| `01 流量获客` | 短视频/直播/小红书/朋友圈的内容与引流方法、投流、私域引流、AI 工具做流量 | 客户进店后的成交话术（→02） |
| `02 聊客成交` | 面诊、微信、电邀的沟通话术，异议处理、压单、FABE 结构、需求分析 | 术后回访与客诉处理（→05） |
| `03 美学设计` | 面部美学评估、轮廓/亚单位/比例设计、看脸培训、设计方案讲解逻辑 | 产品材料本身的理化特性、适应症（→04） |
| `04 医学材料学` | 玻尿酸/肉毒素/仪器/耗材的特性、适应症禁忌、并发症处理、医学原理讲解 | 设计方案本身（→03） |
| `05 医疗售后` | 术后护理、客诉应对、满意度挽回、复购与转介绍 | 售前沟通（→02） |
| `06 团队搭建` | 招聘选人、育人带教、绩效考核、组织管理、团队会议、老板/管理者视角 | 个人获客技巧（→01） |
| `07 商业认知` | 行业趋势、商业模式、创业与 IP、认知类分享、行业分析 | 具体执行 SOP（→01~06 各板块） |
| `08 无法鉴别` | 判不出板块、内容过短过碎、无实质信息、录音质量存疑 | — |

## 判定优先级（冲突时按顺序）

1. **看这段内容要解决的问题发生在客户旅程的哪一环**
   获客 → 聊客 → 设计 → 成交 → 售后，越靠后的环节优先（避免"讲面诊时顺带提到抖音引流"被误判成 01）
2. **看听众是谁**
   对客户讲 → 02/03；对员工讲 → 06；对同行/老板讲 → 07；讲疾病与材料 → 04
3. **看是不是医学知识本体**
   只要主体是"这个材料/这个医学原理是什么" → 04，即使出现在面诊场景里
4. **看有没有实质内容**
   通篇闲聊、只有几句、听不出在讲什么 → `08 无法鉴别`（理由写清原因）
5. 以上都判不出来 → `08 无法鉴别`，理由里写清"混杂了哪几个板块"或"内容不足"

## 置信度规则

- `confidence >= 0.8`：主旨明确，几乎无歧义 → 直接归到对应板块
- `0.6 <= confidence < 0.8`：大致能判，但有少量跨板块内容 → 归到对应板块，理由里注明
- `confidence < 0.6`：**强制归到 `08 无法鉴别`**，交给人工

## 辅助信号：听悟文件夹（dir_id）

每篇稿子的 front-matter 里有 `dir_id`，是用户在通义听悟里**人工归的文件夹**。
同一 `dir_id` 的稿子主题往往相近 —— 可以拿同文件夹里已判定稿子的结果做参照，提高一致性。

但**不能盲信**：文件夹可能是按时间、按项目、按客户建的，未必按板块。
**以内容为准、文件夹为辅。**

## 输出格式（plan.json）

```json
[{"id": 1, "target": "02 聊客成交", "confidence": 0.92,
  "reason": "面诊现场沟通话术，含 FABE 结构与异议处理"}]
```

`target` 只能是以下 9 个合法值之一：
`00 待分类` / `01 流量获客` / `02 聊客成交` / `03 美学设计` / `04 医学材料学` / `05 医疗售后` / `06 团队搭建` / `07 商业认知` / `08 无法鉴别`
